# Rama Flowers Website

## VS Code quick start
1. Extract this folder.
2. Open the folder in VS Code.
3. Install the "Live Server" extension.
4. Right-click `index.html` → "Open with Live Server".
5. Replace `YOUR-DOMAIN.com` in all HTML files, `robots.txt`, and `sitemap.xml` after buying your domain.
6. Replace the remote flower photos with your own shop/product photos when available.
7. Upload the folder to your hosting.
